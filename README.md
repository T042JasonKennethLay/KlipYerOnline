# KlipYerOnline

AI auto-clipper: kasih link video (YouTube / Twitch VOD), keluar clip vertikal 9:16 yang siap upload, lengkap dengan layout facecam + gameplay dan caption kata per kata.

## Fitur (rencana)

- Cari momen menarik dari heatmap, loudness audio, dan chat
- Download hanya potongan video yang dipakai
- Transkrip per kata untuk caption karaoke
- Render 9:16 dengan layout facecam di atas, gameplay di bawah

## Tech stack

- Python, yt-dlp, numpy, scipy
- ffmpeg
- faster-whisper
